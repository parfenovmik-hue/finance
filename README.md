# Финансы — PWA для учёта на iPhone

Приложение устанавливается на экран «Домой» через Safari и работает без интернета.
Данные хранятся на телефоне и синхронизируются с твоей Google-таблицей.

## 1. Выложить на GitHub Pages

1. На github.com нажми **New repository**. Название: `finance`, видимость: **Public**
   (бесплатный Pages работает только для публичных репозиториев; в коде нет твоих данных).
   Галочки ставить не нужно, нажми **Create repository**.
2. На странице пустого репозитория нажми ссылку **uploading an existing file**.
3. Перетащи из Finder всё содержимое папки `Панель-приложение`: `index.html`, `app.js`,
   `styles.css`, `sw.js`, `manifest.webmanifest`, папку `icons` (папку `google-apps-script` можно тоже).
   Нажми **Commit changes**.
4. **Settings → Pages**. В разделе *Build and deployment* выбери Source: **Deploy from a branch**,
   Branch: **main**, папка **/ (root)**, нажми **Save**.
5. Через 1–2 минуты приложение будет доступно по адресу `https://ЛОГИН.github.io/finance/`.

## 2. Установить на iPhone

Открой адрес в **Safari**, нажми «Поделиться» → «На экран Домой».

## 3. Подключить Google-таблицу (по желанию, но рекомендую)

1. Создай **новую** Google-таблицу, например «Финансы 2026».
2. В таблице открой **Расширения → Apps Script**, удали всё содержимое и вставь код из
   `google-apps-script/Code.gs`.
3. В строке `const SECRET = '…'` впиши свой длинный пароль (любой набор символов). Сохрани (💾).
4. **Начать развёртывание → Новое развёртывание**. Шестерёнка → **Веб-приложение**.
   «Выполнять как»: **Я**, «У кого есть доступ»: **Все**. Нажми **Начать развёртывание** и выдай доступ
   (Google предупредит, что приложение не проверено: «Дополнительно» → «Перейти…» — это твой собственный скрипт).
5. Скопируй URL веб-приложения (заканчивается на `/exec`).
6. В приложении: ⚙️ → «Google Таблица» → вставь URL и секрет → «Синхронизировать сейчас».
   Скрипт сам создаст листы «Операции», «Счета», «Категории», «Долги».

После изменения кода скрипта нужно заново развернуть его: **Управление развёртываниями → ✏️ → Версия: новая**.
Тогда URL останется прежним.

Лист «Операции» удобно использовать для сводных таблиц и графиков. Не меняй вручную
серые технические колонки и не переставляй колонки.

## Обновление приложения

Замени изменённые файлы в репозитории (Add file → Upload files) и увеличь номер `CACHE`
в `sw.js`. На телефоне новая версия загрузится со второго открытия.

## Что внутри

- Операции: расход, доход, операции между счетами, обмен RUB↔USDT по фактическому курсу,
  долги (платёж, новый займ, «мне должны»).
- Главный экран: деньги на счетах, итог в рублях, доходы и расходы за месяц, остаток долгов,
  серия дней с записями.
- Отчёт за месяц: доходы и расходы по категориям, погашение долгов, график за полгода, экспорт в CSV.
- Резервная копия в JSON (⚙️ → Данные).

Быстрая запись: введи сумму и тапни категорию, операция сохранится сразу.
Комментарий, если нужен, пиши до выбора категории.
